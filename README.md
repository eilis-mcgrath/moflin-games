Moflin Play

A small collection of browser games for young children, starring a Moflin they choose at the start. Built as a single self-contained HTML file — no installation, no account, no app store.

Play it here: (add your GitHub Pages link once it's live, e.g. https://yourusername.github.io/moflin-play/)

The games
🧶 Moflin Maze — Drag the Moflin through a maze to its nest. Some mazes have a hurdle to hop over, a chute that slides you back, or a ladder that gives you a shortcut.
👑 Moflin Dress Up — Drag hats, glasses and wings onto the Moflin, then press the camera button for a photo.
🏁 Moflin Races — Pick a car, train, plane or horse and tap the Moflin to race three animal friends. Tapping keeps the Moflin in the lead.
🔤 Moflin Spelling — Look at the picture, then drag the letter blocks into the right order to spell the word.
Who it's for

Designed for a young child, around age 5, who may not read yet — the whole game is playable by picture and touch alone, with no text instructions to follow.

How to play it

Just open index.html in any browser, on a phone, tablet or computer. Nothing to install.

To host it so others can play from a link, upload index.html to a static site host such as GitHub Pages or Netlify Drop.

About the build
A single HTML file with inline CSS and JavaScript — no build step, no external libraries.
All artwork is hand-drawn SVG, generated in code rather than image files.
Works offline once loaded, aside from one optional web font.
